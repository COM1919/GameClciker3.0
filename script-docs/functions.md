# 脚本设置界面 GUI API 文档

> 详细的内容，可以前往学习 ImGui 库，因为 GC 使用的是 ImGui 作为渲染。

## Button - 创建一个按钮

该函数在 UI 中创建一个按钮。按钮的大小由提供的宽度和高度决定。如果用户点击了按钮，则返回 `true`。

| 项目 | 说明 |
|------|------|
| **返回值** | `Bool` 类型：用户是否点击按钮 |
| **参数** | • `字符串`：按钮上显示的文本标签（`####` 后面的文字会自动隐藏，不能与其他控件相同）<br>• `整数`：按钮的宽度<br>• `整数`：按钮的高度 |
| **注意** | 宽度和高度必须同时提供，不能省略。 |

```lua
if Button("点我####隐藏的文字", 500, 500) then
    PrintLog("[FreeF5]大大的按钮被点击了")
end
```

## Checkbox - 创建一个复选框

该函数在 UI 中创建一个复选框。复选框的初始状态由提供的 `bool` 类型决定。如果用户更改了复选框的状态，则返回更新后的状态。

| 项目 | 说明 |
|------|------|
| **返回值** | `Bool` 类型 |
| **参数** | • `字符串`：复选框旁边显示的文本（不能与其他控件相同）<br>• `Bool` 类型：复选框的初始状态（`true` 为选中，`false` 为未选中） |

```lua
-- a是全局变量，如果放在GUI渲染函数中，会导致a的值一直被重置
a = false
-- 渲染函数中:
a = Checkbox("帮我打上勾####隐藏的文字", a)
```


## SliderInt - 创建一个整数滑块

该函数在 UI 中创建一个整数滑块。滑块的初始值、最小值、最大值和格式字符串由提供的参数决定。如果用户更改了滑块的值，则返回更新后的值。

| 项目 | 说明 |
|------|------|
| **返回值** | `整数`：修改后的值 |
| **参数** | • `字符串`：滑块旁边显示的文本标签（不能与其他控件相同）<br>• `整数`：滑块的值（必须为变量）<br>• `整数`：滑块的最小值<br>• `整数`：滑块的最大值<br>• `字符串`：滑块值的格式字符串（例如：`"%d"`，如果你不知道格式字符串，请自行搜索相关教程） |

```lua
-- t是全局变量
t = 19
-- 以下函数在GUI渲染函数中
t = SliderInt("我是文字####看不见我", t, 10, 100, "%d")
```

## RangeSliderInt - 创建一个整数范围滑块

该函数在 UI 中创建一个整数范围滑块，可以同时拖动滑块的上下限，常用于设置 CPS 波动范围（CPS 设置界面使用的就是该控件）。如果用户更改了滑块的范围，则返回更新后的两个值。

| 项目 | 说明 |
|------|------|
| **返回值** | `2个整数`：范围的最小值和最大值 |
| **参数** | • `字符串`：滑块旁边显示的文本标签（不能与其他控件相同）<br>• `整数`：范围的最小值（必须为变量）<br>• `整数`：范围的最大值（必须为变量）<br>• `整数`：滑块允许的最小值<br>• `整数`：滑块允许的最大值<br>• `字符串`：滑块值的格式字符串（例如：`"%d"`，如果你不知道格式字符串，请自行搜索相关教程） |

```lua
-- 全局变量
minCps = 10
maxCps = 14
-- 以下函数在GUI渲染函数中
minCps, maxCps = RangeSliderInt("####范围滑块", minCps, maxCps, 1, 40, "%dCPS")
```

## Combo - 创建一个下拉框

该函数在 UI 中创建一个下拉框，点击后可以从列表中选择其中一个选项。如果用户更改了选项，则返回更新后的选项索引。

| 项目 | 说明 |
|------|------|
| **返回值** | `整数`：当前选中的选项索引（从 0 开始） |
| **参数** | • `字符串`：下拉框旁边显示的文本标签（不能与其他控件相同）<br>• `整数`：当前选中的选项索引（从 0 开始，必须为变量）<br>• `数组(table)`：选项列表，是一个字符串数组，例如：`{"选项一", "选项二", "选项三"}` |

```lua
-- 全局变量
select = 1
-- 以下函数在GUI渲染函数中
select = Combo("####下拉框", select, {"选项一", "选项二", "选项三"})
Text("你选中了第" .. (select + 1) .. "个选项")
```

## MessageBox - 显示一个消息框

该函数显示一个包含消息、标题和按钮的消息框。消息框的类型由提供的整数决定。如果用户点击了 **确定** 按钮，则返回 `1`；如果用户点击了 **取消** 按钮，则返回 `2`。

| 项目 | 说明 |
|------|------|
| **返回值** | `整数`：代表用户点击的按钮（`1` 为确定，`2` 为取消），`-1` 为用户还没有点击按钮！ |
| **参数** | • `字符串`：消息框中显示的消息内容<br>• `字符串`：消息框的标题<br>• `整数`：消息框的类型（`0` 表示 **确定** 按钮，`1` 表示 **确定** 和 **取消** 按钮） |

```lua
function render()
    -- 用户没有点击按钮时，一直都会-1
    if MessageBox("我是弹窗消息", "我是标题", 0) == 1 then
        PopTip("不可以点取消!", 1, 1)
    end
end
```

函数需要放在上一个控件的后面，当用户鼠标停留在上一个控件时，就会显示帮助内容。

> **注意：** 该函数无法在 3.28 以前的版本使用，3.28 及以上可以使用。

| 项目 | 说明 |
|------|------|
| **返回值** | 无 |

```lua

```

## PopTip - 显示一个弹出提示

该函数显示一个弹出提示，提示内容由提供的字符串决定，提示的持续时间和类型由提供的整数决定。

| 项目 | 说明 |
|------|------|
| **返回值** | `Bool` 类型，时间到了后，就会返回 `false` |
| **参数** | • `字符串`：弹出提示中显示的文本内容<br>• `整数`：弹出提示的持续时间（以秒为单位）<br>• `整数`：弹出提示的类型（`1` 为消息，`2` 为警告，`3` 为错误） |

```lua
-- 全局变量
ret = true
function render()
    if ret then
        ret = PopTip("我弹出来啦!", 1, 1)
    end
    -- 当ret为false时，代表PopTip已经到了时间，就不显示了
end
```

## RadioButton - 创建一个单选按钮

该函数在 UI 中创建一个单选按钮。单选按钮的标签由提供的字符串决定，按钮的 ID 由提供的整数决定，初始状态由提供的整数决定。如果用户选中了该单选按钮，则返回更新后的状态。

| 项目 | 说明 |
|------|------|
| **返回值** | `整数` |
| **参数** | • `字符串`：单选按钮旁边显示的文本标签（不能与其他控件相同）<br>• `整数`：单选按钮的 ID<br>• `整数`：当前被选中的 ID（当当前单选按钮的 ID 和被选中的 ID 相同时，就会显示被选中） |

> **注意：** 该函数在 3.28 前无法使用，会报错：参数过多或太少。

```lua
-- t是全局变量
t = 1 --选项的ID，可以随意，但必须为数字且不要太大!
-- 以下函数在GUI渲染函数中
t = RadioButton("我是文字1####隐藏的文字", 1, t)
t = RadioButton("我是文字2####隐藏的文字", 2, t)
t = RadioButton("我是文字3####隐藏的文字", 3, t)
t = RadioButton("我是文字4####隐藏的文字", 4, t)
t = RadioButton("我是文字5####隐藏的文字", 5, t)
Text("你选中了" .. t) -- ..是连接符，代表把变量t连接到字符串
```

## SetCursorPos - 设置 UI 中光标位置

不是设置鼠标位置，而是设置下一个 UI 中的光标位置来控制下一个控件出现的位置。

|------|------|

```lua
SetCursorPos(-1, -1)
```

## BeginChild - 开始一个子窗口

该函数在 UI 中创建一个子窗口（子区域），用于将一批控件分组显示在同一个区域中（可以配合高度实现滚动区域）。`BeginChild` 必须与 `EndChild` 成对使用，无论 `BeginChild` 返回什么，都必须调用 `EndChild`。

| 项目 | 说明 |
|------|------|
| **返回值** | `Bool` 类型：子窗口是否打开（一般不需要判断，直接使用即可） |
| **参数** | • `字符串`：子窗口的唯一标识<br>• `整数`：子窗口的宽度（`0` 为自动填满可用宽度）<br>• `整数`：子窗口的高度（`0` 为自动填满可用高度）<br>• `Bool类型（可选）`：是否显示边框（`true` 为显示，`false` 为不显示，默认为 `false`） |

```lua
-- 渲染函数中:
if BeginChild("####脚本设置区域", 600, 200, true) then
    Text("我是子窗口里面的内容")
    SliderInt("####子窗口中的滑块", 10, 1, 100, "%d")
end
EndChild()
```

## DrawCircle - 绘画一个圆的边框

绘制一个圆形边框。

| 项目 | 说明 |
|------|------|
| **返回值** | 无 |
| **参数** | • `整数`：圆心 X 坐标<br>• `整数`：圆心 Y 坐标<br>• `整数`：半径<br>• `小数`：线宽 |

---

## DrawCircleFilled - 绘画一个填充的圆

绘制一个填充圆形。

| 项目 | 说明 |
|------|------|
| **返回值** | 无 |
| **参数** | • `整数`：圆心 X 坐标<br>• `整数`：圆心 Y 坐标<br>• `整数`：半径 |

---

## DrawText - 绘画文本

在指定位置绘制文本。

| 项目 | 说明 |
|------|------|
| **返回值** | 无 |
| **参数** | • `整数`：文本左上角 X 坐标<br>• `整数`：文本左上角 Y 坐标<br>• `字符串`：要绘制的文本 |

---

## DrawImage - 绘画一个图片

在指定位置绘制图片。

| 项目 | 说明 |
|------|------|
| **返回值** | 无 |
| **参数** | • `整数`：图片左上角 X 坐标<br>• `整数`：图片左上角 Y 坐标<br>• `整数`：图片宽度<br>• `整数`：图片高度<br>• `字符串`：图片文件路径 |

图片文件的路径，默认在脚本当前的文件夹目录（解压后的文件夹，也就是 `temp` 文件夹中）。脚本只能够读取自己文件夹下的文件，无法读取 `temp` 文件夹之外的文件。所以你可以将图片放在压缩包中，然后直接使用文件名就可以显示图片。如每个脚本都有的封面图，可以使用 `DrawImage("icon.bmp")` 来显示图片。
