> 文档中 API 仅供 **最新版 GC 连点器** 使用，旧版本将 **不再提供任何支持**

## RenderMessageBox - 显示一个消息框

该函数显示一个包含消息、标题和按钮的消息框。消息框的类型由提供的整数决定。如果用户点击了 **确定** 按钮，则返回 `1`；如果用户点击了 **取消** 按钮，则返回 `2`。**该函数会一直等到用户点击按钮才继续运行。**

| 项目 | 说明 |
|------|------|
| **返回值** | `整数`：代表用户点击的按钮（`1` 为确定，`2` 为取消） |
| **参数** | • `字符串`：消息框中显示的消息内容<br>• `字符串`：消息框的标题<br>• `整数`：消息框的类型（`0` 表示 **确定** 按钮，`1` 表示 **确定** 和 **取消** 按钮） |

```lua
function main()
    if RenderMessageBox("我是弹窗消息", "我是标题", 0) == 1 then
        RenderPopTip("不可以点取消!", 1.5, 3)
    end
end
```

## RenderPopTip - 显示一个弹出提示

该函数显示一个弹出提示，提示内容由提供的字符串决定，提示的持续时间和类型由提供的整数决定。

| 项目 | 说明 |
|------|------|
| **返回值** | 无 |
| **参数** | • `字符串`：弹出提示中显示的文本内容<br>• `小数`：弹出提示的持续时间（以秒为单位）<br>• `整数`：弹出提示的类型（`1` 为消息，`2` 为警告，`3` 为错误） |

```lua
RenderPopTip("我弹出来啦!", 2.4, 1)
-- 弹出一个提示框，时长为2.4秒，类型为1（消息）
```

> 该函数不会阻塞运行，可以在任何地方使用。

## PrintLog - 打印日志

该函数用于打印日志信息。

| 项目 | 说明 |
|------|------|
| **返回值** | 无 |
| **参数** | • `字符串`：日志消息<br>• `整数`：日志级别（`1` 为普通消息，`2` 为警告消息，`3` 为错误消息） |

**日志字符串标准格式：** `[<脚本名字>]<日志内容>`

其中的 `[<脚本名字>]` 必须放在输出字符串前，`<日志内容>` 为你要输出的内容，例如：

```lua
PrintLog("[AutoFishingRod]出现未知错误", 3)
```

> 注意：必须遵循日志输出的标准，否则会导致日志难以阅读。

## GetKeyDown - 检查按键是否按下

该函数检查指定按键是否被按下。

| 项目 | 说明 |
|------|------|
| **返回值** | `Bool` 类型：是否按下 |
| **参数** | • `整数`：按键代码<br>• `Bool类型（可选）`：仅获取人类点击，该选项有助于过滤掉自己的模拟点击<br>• `整数（可选）`：获取按键状态的方式 |

**获取按键状态的方式对照表**

| 整数值 | 解释 |
|:---:|:---|
| 1 | 使用全局系统钩子获取按键状态 |
| 2 | 使用系统 API 监听按键状态 |
| 3 | 以上都使用，将由 GC 自动选择 |

> **注意：** 该参数 **不一定会生效**，只是作为建议。因为如果想要使用 `仅获取人类点击`，则会强制使用 `全局系统钩子` 获取按键状态。

**仅获取人类点击实际使用示例**

```lua
function main()
    if GetKeyDown(32, true) then -- 判断是否是人类的点击，过滤模拟的按键状态
        SetKeyUp(32) -- 32是空格
        Sleep(1000 / 12) -- 12 CPS
        SetKeyDown(32) -- 因为这里模拟按下，所以判断是否是人类的操作
    end
end
```

## SetKeyDown - 模拟按键按下

该函数模拟按下指定按键。

| 项目 | 说明 |
|------|------|
| **返回值** | 无 |
| **参数** | • `整数`：按键代码<br>• `整数（可选）`：点击方式 |

**点击方式 ID 对照表**

| 数字 ID | 对应方式 | 含义 |
|:---:|:---|:---|
| 0 | `SC_MOUSE_EVENT` | 使用 `mouse_event` API 来模拟系统点击消息 |
| 1 | `SC_SEND_INPUT` | 使用 `SendInput` API 来模拟底层点击（该模式支持基岩版） |
| 2 | `SC_POST_MESSAGE` | 使用 `PostMessage` API 向窗口发送点击消息 |

> 如果需要在最新基岩版中编写脚本，那么就需要使用 `SC_SEND_INPUT`，也就是参数传入 `1`。其他的点击方式在最新基岩版无效！
